# OLX Design System — merge bundle

Everything needed to run the Storybook that holds the OLX design system (tokens + components)
and the captured page flows for Classifieds, Property and Motors.

Drop these into your OLX design system folder, then:

    npm install
    npm run dev          # Storybook on http://localhost:6006

## What's in the bundle

| Path | What it is | Size |
|---|---|---|
| `design-kit/templates/` | **48 captured pages**, built and browsable. `classifieds/`, `property/`, `motors/`, each with `desktop/` and `mobile/`. Plus `_assets/` (localised fonts + icons) and `templates.json` (the manifest both the kit and Storybook read). | 35 MB |
| `design-kit/sites.json` | Which pages and flows each product has, and where they come from. Edit this to add a page or a journey. | — |
| `motors-html/` | The **raw Motors server HTML** (29 pages × desktop/mobile) plus `manifest.json`. This is the untouched fetch — `design-kit/templates/motors/` is built from it. | 19 MB |
| `css/` | The design system itself: `tokens.css`, `base.css`, `components.css` (all the `olx-*` classes), entry point `olx.css`. | 44 KB |
| `tokens/tokens.json` | Source of truth for colour, type, spacing. `dist/tokens.js` is the JS build. | — |
| `src/foundations/`, `src/components/` | Foundations stories and the React wrappers (Button, Badge, Chip, Alert, Field, Breadcrumb, ListingCard). | — |
| `src/patterns/` | Stories for the rest of the system, straight `olx-*` markup: Navigation, Home page, Listing page, Ad detail, Footer, Layout, Forms. | — |
| `src/templates/` | `PageFrame` + `FlowFrame` (the iframe viewers) and `generated/` — the page and flow stories, regenerated by script. | — |
| `src/Overview.stories.tsx` | The front-door page and the index of every capture. | — |
| `scripts/` | `capture-site.mjs`, `pull-motors-html.mjs`, `build-templates.mjs`, `localize-assets.mjs`, `build-template-stories.mjs`, `build-tokens.mjs`. | — |
| `.storybook/` | `main.ts` (serves `design-kit/templates` at `/templates`), `preview.ts` (theme toolbar, sidebar order). | — |

Not included: `node_modules/`, `storybook-static/`, and `design-kit/raw/` (85 MB of raw
pre-build captures — regenerate with `npm run capture:sites` if you ever need them).

## The pages

48 pages, desktop and mobile:

- **Classifieds (9)** — home, category listing, vehicles category, search results, ad detail,
  seller profile, post an ad, chat, 404
- **Property (10)** — hub, for sale, for rent, houses, apartments, commercial plots,
  shops & offices, price-filtered, detail (sale), detail (rent)
- **Motors (29)** — home, new cars (+ listing/body-type/make/model/variant), compare,
  compare details, reviews (+ model, detail), inspection, auction sheet, finance (+ bank),
  insurance (+ TPL, partner), tyres, batteries, oil grades

8 flows step through them in order; the step buttons and the pages' own links both work.

Three deliberate changes to every capture:

1. **Scripts stripped** — anything that only appears after JS runs (dropdowns, modals, filter
   sheets) is not in the capture.
2. **Links rewritten** — a link to another captured page opens it inside the frame; everything
   else opens the live site in a new tab.
3. **Forms inert** — nothing can be submitted. No lead, finance, insurance or inspection
   enquiry can be sent from the kit.

Fonts and icons are local (`design-kit/templates/_assets/`) because the OLX CDNs restrict them
to `www.olx.com.pk`; left remote they silently fall back to a system font.

## Rebuilding

    npm run capture:sites    # re-render classifieds + property from live (Chrome, GET only)
    npm run capture:motors   # re-fetch Motors server HTML
    npm run build:kit        # templates -> localise assets -> regenerate stories
    npm run build:tokens     # tokens.json -> css/tokens.css + dist/tokens.js
    npm run build:storybook  # static build

Capturing only navigates and scrolls — it never clicks, types or submits, and pages that
redirect to a login wall are skipped rather than saved.
